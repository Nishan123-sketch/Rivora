# Rivora level forecasting v4 — completed verification, 8 November 2026

1. **Original readiness issue.** The supplied zero-ready state was not reproduced: the initial live API reported 759 ready out of 789. Zero experimental grades and zero validated warning models are separate, intentional states. Old level results could expire between hourly refreshes. More materially, request-time fitting/refitting meant the serving model differed from the evaluated model; final-test availability also affected variant choice. Live requests now load saved predictions from immutable, compatible artifacts. A locked ten-minute inference job and daily training schedule replace duplicate scheduled fitters.

2. **Data quality.** Audited all 789 eligible official-threshold gauges and 3,106,584 stored raw observations. 1,307,226 raw rows lack independently acceptable provenance; these are preserved but excluded unless separately reconciled. 159 stations have step/rise flags; 268 have long-constant flags. These flags do not establish sensor error. Raw totals concern all stored history; hourly missingness, gaps and rainfall coverage concern the derived recent 366-day window. Per-station details are in `level-forecast-v4/station-quality.json`. Historical datum epochs, relocations and original data-arrival/revision vintages remain unavailable. Existing reference holds, including Yongdam, remain intact.

   Taehwa station 207 / external 2201670: authenticated official hourly history reconciled 11,511 rows in a separate derived table. Of 9,722 timestamp overlaps, none differed. Raw water readings were not overwritten. Official point rainfall gauge 22014080 is approximately 0.031 km away: 8,943 received hourly rows, 8,880 newly stored provider-specific rows. Response evidence hashes normalized records, not raw HTTP response bytes. This establishes source agreement, not a historical datum-change certificate. The substantial historical level step remains flagged.

3. **Eligibility.** 530 stations have sufficient provenanced chronological evidence for an evaluated level artifact. Another 225 lack sufficient provenanced chronological samples, 28 lack recent provenanced coverage and six remain held for measurement/reference review. Data quality eligibility alone does not establish advanced-model acceptance.

4. **Training.** 3,230 full candidate station–horizon models were fitted (Ridge, ElasticNet and histogram gradient boosting). Persistence and bounded trend were evaluated separately. There are 530 station artifact bundles and 1,590 evaluated station–horizons. Four nonconverged ElasticNet fits were excluded. No neural model or GPU requirement was introduced.

5. **Independent acceptance.** Eight advanced station–horizon models across five stations passed the frozen level-research acceptance gates: Taehwa 1/3/6h; Jungnang 1018675 6h; Gunmun 1101635 1h; Dongyeon 1101670 1h; Neobudae 1018695 1/3h. Other evaluated horizons retain explicitly labelled persistence demonstrations. This is retrospective acceptance, not operational certification. No final-test result was used to tune hyperparameters or retry rejected candidates.

6. **Live availability.** At the integration snapshot (8 November 2026, 15:27 KST), 530 stations were ready. API overview, selected Taehwa, quality endpoint and the Vite proxy returned HTTP 200. Readiness can change with authentic input freshness and gaps. First API checks took 6.88 s and 4.62 s; quality took 0.727 s and the warmed proxy 0.056 s. These are individual measurements, not a load-test guarantee. No model fitting occurs in request handling; large report loading is cached by file modification time.

7. **Errors by horizon.** Taehwa final independent chronological holdout: 1h Ridge N=1,405, MAE 0.036994 m, RMSE 0.047460 m; 3h ElasticNet N=1,403, MAE 0.056185 m, RMSE 0.070829 m; 6h ElasticNet N=1,400, MAE 0.060739 m, RMSE 0.075866 m. Exact periods, bias, median/p95 absolute error and all eligible station metrics are in the HTML/CSV comparison. Network sample-weighted selected-method MAE/RMSE are 0.008786/0.044570 m (1h), 0.020840/0.106695 m (3h), and 0.032992/0.145865 m (6h). Uneven station sample counts and calm periods mean these aggregates cannot certify flood performance.

8. **Persistence comparison.** Taehwa baseline MAEs are 0.062327, 0.147969 and 0.211700 m: selected-method improvements are 40.65%, 62.03% and 71.31%. A separate fixed-calendar 21-station pooled Ridge experiment was executed. Station-specific Ridge outperformed pooling overall; pooled weights were not deployed. No basin group met the required three eligible common-period stations. Pooled results use their own common-calendar comparison and must not be conflated with station-specific v4 splits. See `performance.html` for the requested real-number comparison tables.

9. **Rising/high-water performance.** Taehwa rising-water MAEs are 0.035351/0.046047/0.062707 m (205 samples, two separated episodes), compared with persistence 0.069512/0.143073/0.184488 m. Training-decile high-water proxy MAEs are 0.038077/0.057076/0.062334 m (705 samples, one episode), compared with 0.061943/0.144099/0.205731 m. This proxy is not an official flood threshold. Heavy point rainfall evaluation has only three hours in one episode; flood/storm reliability remains insufficient. Temporal episodes/72-hour blocks are not verified independent flood-event labels.

10. **Leakage prevention.** The policy was fixed before fitting. Level partitions use chronological 60/72/84% boundaries with a 78-hour purge covering the 72-hour maximum lag plus six-hour target; minimum sizes 720/168/168/168. Train-only scaling and regime cutoffs, backward-only alignment, no invented rainfall/interpolation, two rolling development folds, separate interval calibration and final test, 500 block resamples and at least eight time blocks protect evaluation. Acceptance needs at least 5% MAE improvement, RMSE no worse, positive lower improvement confidence bound, and rising/high-water checks where sample minimums apply. Final held-out outcomes do not alter candidate selection. Artifact compatibility checks policy, engine, runtime, checksum and actual database station identity. Regression tests exercise these properties.

11. **Uncertainty.** Taehwa empirical nominal-90% residual intervals achieved 84.9822% (1h), 87.7406% (3h) and 91.4286% (6h) test coverage. The 1h interval is withheld because it fails the frozen 85% lower gate; rounding cannot make it pass. The 3h/6h empirical radii are 0.109841/0.131485 m, with 15 calibration and 20 test time blocks. These are empirical coverage checks, not calibrated flood probabilities or guaranteed future coverage. Non-hourly baseline origins and missing-feature fallback intervals are withheld. Forecast horizons are measured from the actual input observation; advanced models use hourly inputs, not the page refresh time.

14. **Remaining limits and preservation.** Unavailable stations retain exact reasons and do not receive zero/fabricated predictions. Source gaps/stale observations can suppress output. Already-evaluated persistence is explicitly distinguished from an accepted advanced model; non-hourly baseline performance is not independently established. No archived forecast-rainfall vintages, catchment rainfall, certified historical datum/relocation epochs or verified flood labels were fabricated. Stored history permits reproduction in this database, but a source-only ZIP is not a database backup and original arrival/revision vintages are unavailable. Warning files match their pre-work hashes: 493 historical records, 307 issuances, 40 complete intervals, 490,609 usable samples and 81 events remain preserved. The pre-2025/2025/2026 warning partitions, 72-hour storm purge, calibration/event minima and `INSUFFICIENT_CALIBRATION_OR_THRESHOLD_EVENTS` outcome were not changed. No warning probability is enabled.

15. **Suitability.** The eight accepted advanced horizons support retrospective research. Remaining persistence outputs are evaluated demonstrations. The system is not established as an operational flood forecast or official warning service; scarce independent flood/storm evidence is the major remaining scientific limitation.

To operate: keep the backend running and prediction/advanced jobs enabled. `npm run ml:levels:refresh` performs saved-artifact inference; `npm run ml:levels:train` explicitly forces bounded retraining; `npm run ml:levels:benchmark` repeats the pooled experiment. Run these from `backend`. Daily automatic training uses recent authentic data; new artifact versions may pass or fail the unchanged gates. The current development frontend stays at http://localhost:5173 and its backend is port 5001. Fresh installations default to 5000 unless a public Vite target override is set. Preserve a private database backup and configure credentials separately; the ZIP deliberately contains neither credentials nor a database dump.
